## 3. マップ

- 日本地図＋太平洋の向こうの **アメリカ大陸** に **58駅**、駅と駅を結ぶ **85路線**（うち **海路7本**：函館–青森、山口–福岡、岡山–高松、神戸–徳島、広島–松山、東京–ホノルル、ホノルル–ロサンゼルス）。
- 路線の途中にマスを自動配置（駅間の距離40ごとに1マス）。乱数のシード値を固定しているので、毎回同じマップになります。
- マスの総数は **226**（駅58＋途中のマス168）。

### 3.1 ガバメントクラウドの5CSPとアメリカ大陸
- 5つのCSPの名前は、一部を「○」で伏せ字にして表示する（例：A○S、G○○gle Cloud）。地図の左下に「※ 登場する会社名・サービス名・団体名などは架空のものです」と小さく注記する。
- CSPの駅の街の絵には、特定の会社を思わせる建物・社屋・配色・ロゴ・文字を入れない（その街の一般的な風景だけを描く）。
- ガバメントクラウドの5つのクラウド事業者（CSP）を **駅＝目的地** として置く。地図では青い枠と ☁ の印、駅名の下に所在地を表示。
  - **さ○らのクラウド**：北海道・石狩のデータセンター（札幌と旭川の間）。国産。
  - **A○S**（シアトル）・**Az○re**（レドモンド）・**G○○gle Cloud**（マウンテンビュー）・**O○I**（オースティン）：米国産なので **アメリカ大陸** に置く。
- アメリカ大陸は、実際の米国本土の形（フロリダ半島・メキシコ湾・五大湖のくぼみなど）を経度・緯度から地図座標へ写して描く（`AMERICA`）。日本からは太平洋をはさんで遠く離れている。
- アメリカ大陸には中継の **ロサンゼルス**・**シカゴ**・**ニューヨーク** の駅もある。日本からは「東京→ホノルル→ロサンゼルス」の海路だけで渡る（東京からロサンゼルスまで29マス）。

### 3.2 空港
- 空港のある駅：札幌・仙台・東京・大阪・福岡・鹿児島（日本側）、ホノルル・ロサンゼルス・シカゴ・ニューヨーク（アメリカ側）。地図では駅の左上に ✈ の印。
- 飛行機カードの行き先になる。地図座標 x が 1300 より東（ホノルルを含む）をアメリカ側とする。
- CSPの駅の物件は「○○リージョン」「マネージドDB」「閉域接続サービス」（標準化業務ではなく独自施策扱い）。
- 目的地を決めるとき、候補（14マス以上先）にCSPの駅があれば **35%の確率でCSPの駅** が選ばれる。目的地ムービーには「☁️ ガバメントクラウド（所在地）」も表示する。

- 駅の規模：小（物件価格×1）・中（×1.8）・大（×3）。大は東京・大阪と、A○S・Az○re・G○○gle Cloud・O○I の6駅。
- 全員 **東京駅** からスタート。

## 5. ゲームの流れ

### 5.1 初期状態
- 所持金 **1億円**、位置は東京駅、カードは「アジャイル急行」1枚。

### 5.2 1か月の流れ

3. 月を進める。4月なら「年度スタート（交付金マス2倍）」の案内。

## 7. ロックイン神

特定ベンダーにしばりつける神様。とりつかれた自治体の手番の最後に悪さをします。

**乗りうつり**：持っている人とほかの人が移動中に同じマスでかち合う（すれちがう）と、相手に乗りうつる。「責任分界点」カードでも押しつけられる。

**ロックイン神のしわざ**

| 確率 | 内容 |
|---:|---|
| 40% | 「独自カスタマイズの追加改修が必要ですね」 −1,000万〜4,000万円×年数補正 |
| 20% | 「そのカードは仕様外です」 カード1枚を捨てられる |
| 15% | 「保守契約を更新します。値上げで」 所持金の1割を払う |
| 10% | 「今回は…値引きしておきます」 +500万円×年数補正（珍しい） |
| 15% | 様子を見ているだけ |

**大ロックイン神**：同じ自治体に **5手番** 居すわると変身（乗りうつると元に戻る）。4手番目には「次のターンで変身しそうだ！」と予告が出る。

大ロックイン神は **毎手番かならず取り立て** をし、居すわるほど取り立て額がどんどん増える。

- 取り立て額＝5,000万〜1億円 × 年数補正 × **取り立て倍率**
- 取り立て倍率＝5手番目 ×1 → 6手番目 ×1.5 → 7手番目 ×2 → …（1手番ごとに +0.5、最大 ×5）
- 請求の文句は「全面リプレースが必要です」「データ移行は別料金です」「ライセンス体系が変わりました」「サポート延長料をいただきます」「独自帳票の改修は特別価格で」からランダム

取り立てに加えて、次のおまけがつくことがある。

| 確率 | 追加の悪さ |
|---:|---|
| 25% | 「他社クラウドへは移せませんよ」 いちばん高い物件を手放す |
| 15% | 「ベンダー独自仕様です」 カードを全部捨てる |
| 60% | なし（取り立てのみ） |

画面の表示：自治体パネルの札に、ロックイン神は居すわり手番数（例「😈 ロックイン神 3/5」）、大ロックイン神は取り立て倍率（例「👹 大ロックイン神 ×2」）が出る。盤面の大ロックイン神は居すわるほど大きくなる。

## 10. 決算（毎年3月）

1. 収入＝持っている物件の「価格×削減率」の合計（その駅を独占していれば2倍）。
2. 所持金がマイナスなら、安い物件から **半値** で売ってマイナスを解消（決算以外のときも同じ。10.1）。
3. 決算画面に各自治体の収入・所持金・売った物件を表示。2026年3月の決算では「移行期限」の演出。

### 10.1 赤字の返済（いつでも）
- 改修費マス・ロックイン神・カード・イベントなどで所持金がマイナスになったら、その場で **安い物件から順に半値で売って** 返済する。プラス（0以上）になったところで止める。
- 物件を1件も持っていなければ **赤字のまま** 進む（次に収入があったときに戻る）。売りきってもまだ足りないときも赤字のまま。
- 売った物件はだれのものでもなくなり、また買える。
- 「💸 ○○は赤字！物件を半値で売って返済した」と、売った物件（駅・受け取った額）を通知とログに出す。通知は、赤字のきっかけになった通知のあとに出す。

## 12. CPU の考え方

- **行き先選び**：目的地に近いマスを優先し、マスの種類で加点・減点（駅＋3、カード＋2.5、交付金＋2、制度改正＋0.5、改修費−2）。ロックイン神を持つ相手とすれちがう道は避け、自分が持っているときは相手とすれちがう道を選ぶ。
- **カード**：補助金申請・共同調達・FinOps最適化は即使用。ロックイン神がついていれば責任分界点かオープン標準を使用。相手がカードを持っていればデータポータビリティを使用。仕様書改定通知・リージョン障害・モジバケ怪獣は50%で使用。目的地まで1マスならウォーターフォール、4マス以上ならプライベートジェット、飛んだ先の空港から目的地までが今より8マス以上近くなるなら国際線フライト／国内線シャトル便、9マス以上なら移行ロードマップ、30マス超ならワープ、目的地がCSPの駅で12マス超ならマルチクラウド、7マス以上なら急行系（DXリニアは14マス以上）。
- **買い物**：削減率の高い物件から、手元に「3,000万円×年数補正」（ロックイン神つきなら2倍）を残せる範囲で買う。

## 13. オンライン版の仕様

### 13.1 構成

```
ブラウザ ──WebSocket── Cloudflare Worker（入口）──► Durable Object「GameRoom」（1部屋＝1つ）
   │                         │
   └── 画面・画像 ◄── 静的ファイル（public/）
```

| ファイル | 役割 |
|---|---|
| `wrangler.jsonc` | Worker名 `aji`、静的ファイル、Durable Object（SQLite型・無料プラン対応）の設定 |
| `src/worker.js` | `/ws/部屋コード` を部屋の Durable Object に振り分け。それ以外は画面ファイルを返す |
| `src/room.js` | 部屋（接続・席・ロビー・チャット）と、ゲーム進行のすべて |
| `public/index.html` | 画面（入口・ロビー・盤面・パネル・サイコロ・モーダル・アジビラ神・チャット） |
| `public/client.js` | サーバーから届いた状態・出来事を描画し、自分の操作だけを送る |
| `public/shared.js` | 駅・路線・物件・カードなどの共通データ（サーバーとブラウザで共用） |

### 13.2 部屋と席
- 入口で名前（10文字まで）を入れ、「部屋をつくる」で5文字の部屋コードを発行。招待URL（`?room=コード`）を送れば同じ部屋に入れる。
- 4つの席から好きな席に座る。座らなければ観戦。1部屋の最大接続数は16。
- **ホスト**（👑）は部屋を作った人。いないときは席に座っている人→接続中の人の順に引き継ぐ。部屋を作った人が戻ればホストに戻る。
- ホストはプレイ期間を選んで「ゲーム開始」、ゲーム中は「中断してロビーへ」ができる。

### 13.2.1 町の名前とアイコン
- 席に座った人は、ロビーの「✏️ 名前・アイコン」か、ゲーム中に自分の欄の ✏️ から、**自分の席の町の名前とアイコン** を変えられる。**ゲーム中はアイコンだけ** 変えられ、町の名前は固定（サーバーもゲーム中の名前の変更は受け付けない）。
- **町の名前**：8文字まで。HTMLで使う記号（不等号・アンパサンド・引用符・バッククォート・円記号）と制御文字は取り除く。空なら既定の名前（みらい市など）。
- **アイコン**：画像を選ぶと、ブラウザで真ん中を正方形に切り取り、192×192 の JPEG（約80KB未満）に縮小してから送る。サーバーは `data:image/(jpeg|png|webp);base64,` 形式で80,000文字以内のものだけ受け付ける。「元のキャラに戻す」で既定のキャラに戻る。
- 変えた名前・アイコンは、地図の列車の名札、自治体の欄、手番表示、通知、到着・カードの全画面表示、決算・最終結果、チャット、ログのすべてに反映。アイコンはゲーム中に変えても、すぐ全員の画面に反映。
- 名前・アイコンは席ごとに部屋の中だけで保存し、その部屋をやり直しても残る。席を立った・別の席に移った・別の人が座ったときは既定に戻す（同じ人が再接続したときは残る）。
- 変更は1人1秒に1回まで。

### 13.3 操作の制限時間

| 操作 | 制限時間 | 時間切れのとき |
|---|---:|---|
| カード使用／サイコロ | 90秒 | サイコロを1個振る |
| 行き先選び | 60秒 | CPU と同じ考え方で自動選択 |
| 買い物 | 60秒 | 買い物を終える |

### 13.4 切断・再接続・途中参加
- ブラウザに保存した識別子で本人を判定。切断した席は CPU が代わりに進め、同じブラウザで開き直すと元の席に戻る。
- ゲーム中でも CPU が担当している席には「この席で参加する」で入れる。
- 全員がいなくなるとゲームは一時停止。10分戻らなければロビーに戻る。

### 13.4.1 イベント通知の表示
- イベントの通知（マスの効果・購入・ロックイン神など）は、パネル右上の **ロゴの位置に重ねて** 表示。下端の細いバーで残り時間が分かる。
- 盤面左上の「⏱ 通知」ボタンで表示時間を切り替え（設定はブラウザに保存）：標準（1倍・最低1.5秒）→ **長め（2倍・最低3秒、初期設定）** → もっと長め（3倍・最低4.5秒）→ 消さない（次の通知まで表示）。
- チャットのお知らせ（基準5秒）にも同じ倍率がかかる。
- 時間の値は `public/client.js` の `TOAST_TIMES`・`TOAST_DEFAULT`・`CHAT_PEEK_BASE` で調整できる。
- 表示時間を延ばしてもゲームの進行速度（サーバー側）は変わらず、次の通知が来たら置き換わる。

### 13.5 チャット
- 画面の右横（スマホは画面下。タップで開閉、未読数を表示）。ロビーでもゲーム中でも使え、観戦中の人も参加できる。
- 1通100文字・改行なし。名前・担当の町・時刻を表示し、名前は列車と同じ色。自分の発言は色を変えて表示。
- 定型文ボタン：よろしく！／ナイス！／ぐぬぬ…／それ買いたかった！／おつかれさま！
- 直近60件を部屋に残し、あとから入った人にも表示。連投は約1秒1通に制限（続けて6通目以降は「送信が早すぎます」）。
- 本文はHTMLとして解釈しない（タグを書いても文字として表示）。
- **折りたたみ**：PCは「たたむ」で幅50pxの縦バーに（バーのどこを押しても開く）。スマホは画面下の見出しをタップで開閉（初回はたたんだ状態）。状態はブラウザに保存。
- **折りたたみ中の通知**（自分の発言は通知しない）：
  - 未読数の赤いバッジ（届くたびに弾む）とバーの点滅
  - 発言内容のお知らせ（名前・町・時刻・本文3行まで。5秒で消え、押すとチャットが開く）
  - 通知音「ポロン」（🔔／🔕で切り替え、設定は保存）
  - ブラウザのタブ名に「(未読数)」を表示
- チャットを開いたまま別のタブを見ているときも、通知音とタブ名の未読数でお知らせ。

### 13.6 サーバーとブラウザのやりとり

| 方向 | 種類 | 内容 |
|---|---|---|
| ブラウザ→サーバー | `hello` | 識別子と名前を送って入室 |
| | `sit` / `stand` | 席に座る／立つ |
| | `config` / `start` / `lobby` | 期間設定／開始／中断（ホストのみ） |
| | `roll` / `card` / `pick` / `buy` / `shopDone` | ゲームの操作（自分の番だけ有効） |
| | `chat` | チャット送信 |
| | `profile` | 自分の席の町の名前・アイコンを変える（アイコンは省略で変更なし、`null` で元に戻す） |
| | `ping` | 接続維持（25秒ごと） |
| サーバー→ブラウザ | `state` | 部屋とゲームの最新状態（人ごとに「自分の席」「ホストか」を含む） |
| | `log` / `logs` | 進行ログ（直近80件） |
| | `toast` / `dice` / `modal` / `closeModal` | 演出（吹き出し・サイコロ・到着／決算／最終結果／アジビラ神） |
| | `chat` / `chats` / `chatErr` | チャット1件／履歴／エラー |
| | `icons` / `icon` / `profileErr` | 全席のアイコン（入室時）／1席のアイコンが変わった／画像のエラー。町の名前は `state` の各席の `town` で届く |

## 14. オフライン版だけの仕様
